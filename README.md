# Amar Project - Phase 1

## Dependencies & Run Instructions
1. Install requirements: `pip install -r requirements.txt` (requires `pandas`, `numpy`, `matplotlib`, `seaborn`).
2. Download the data files (see `data/README.md`) and place them in the `data/` folder.
3. Run notebooks sequentially inside the `notebooks/` directory starting with `01_eda.ipynb`.
